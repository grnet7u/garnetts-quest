# Garnett's Quest — Анарбаяны портфолио

UFE SWE334 · Бие даалт 2. Тоглоом маягийн хувийн портфолио (2D ертөнц + workflow HUD), мөн тоглоомгүй «Энгийн горим».

## Технологи
- React 19 + Vite (JavaScript), CSS, SVG
- Back-end байхгүй (static сайт), Vercel дээр байршуулна

## Ажиллуулах
```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ үүснэ
```
